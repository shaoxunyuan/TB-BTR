# Data use and attribution

The repository distributes curated annotations and analysis materials derived from public transcriptomic studies. Accession, repository and publication links are provided in Supplementary Table S1 and the fixed-case source table.

Original studies contributing to the fixed case:

- Berry et al., 2010: PMID [20725040](https://pubmed.ncbi.nlm.nih.gov/20725040/).
- Kaforou et al., 2013: PMID [24167453](https://pubmed.ncbi.nlm.nih.gov/24167453/).
- Anderson et al., 2014: PMID [24785206](https://pubmed.ncbi.nlm.nih.gov/24785206/).

LM22 and ImmunoStates are third-party reference signatures. Reference matrices and cell mappings retain their original attribution and applicable terms. Inclusion here does not grant broader rights than those provided by their original sources. The manuscript's reference list and source publications should be consulted for citation details.

Public sample identifiers and source-specific pseudonyms support traceability and reproducibility. They should not be used to infer personal identity or treated as universal participant identifiers. Platform accounts, uploaded private cohorts, credentials, original participant codes and internal correspondence are excluded.

No blanket open-source or data license is assigned to the entire collection by this initial deposit. Consult the original source terms before redistribution or reuse, and contact the repository maintainers about permissions for project-authored materials where needed.
